Создай одностраничный мультимедийный сайт-лонгрид (scrollytelling) на русском языке для олимпиады по журналистике. Тема: «Маша едет за границу: экспортный потенциал российской анимации».

Текст статьи, данные и источники УЖЕ ГОТОВЫ — они лежат в папке `content/` рядом с этим промптом. Твоя задача — сайт: вёрстка, графики, интерактив, анимации, переходы и удобное ручное редактирование.

## 1. Контент (не переписывай)

- `content/00-oblozhka.md` … `content/08-vyvod.md` — текст разделов. Используй его как есть. Не сокращай и не перефразируй; можно только расставить переносы и неразрывные пробелы.
- Сноски в тексте — `[^N]`, где N — id из `content/sources.json`. Сделай их кликабельными: клик подсвечивает источник в списке внизу, наведение показывает тултип с названием издания и датой.
- `content/data.json` — все цифры для графиков. Графики и счётчики берут значения ТОЛЬКО оттуда, никаких захардкоженных чисел.
- Если в тексте найдёшь фактическую нестыковку с data.json или sources.json — не исправляй молча, выпиши её в отчёт в конце.

## 2. Технические требования

- Vite + vanilla JS + CSS, статический сайт без бэкенда.
- ВСЕ зависимости — локально через npm: никаких CDN, внешних шрифтов и скриптов. Сайт должен открываться из России без VPN; во вкладке Network — ноль запросов к сторонним доменам.
- Библиотеки: GSAP + ScrollTrigger, D3.js + world-atlas TopoJSON, Lenis, markdown-it (+ плагин для сносок) — всё локально.
- Адаптивность: 375 / 768 / 1440 px. На мобильных анимации упрощаются, но не исчезают.
- Доступность: alt-тексты, контраст AA, подписи к графикам, `prefers-reduced-motion` → анимации заменяются на мгновенные или простые fade.
- Производительность: WebP, lazy loading, анимации только через transform/opacity. Lighthouse Performance ≥ 85 на мобильном.
- Никакой аналитики, трекеров, cookies.

## 3. Шрифт

- Основной — Google Sans Flex, локально через npm (`@fontsource-variable/google-sans-flex` или `@fontsource/google-sans-flex`, проверь точное имя).
- ПЕРВЫМ делом проверь поддержку кириллицы. Если её нет — сообщи и предложи замену с кириллицей (Manrope, Onest или Inter, тоже локально); до моего ответа используй её как fallback для кириллицы.
- Используй вариативные оси (вес, ширина) в анимациях заголовков.

## 4. Ручное редактирование

- Текст правится в `.md`-файлах, цифры — в `data.json`, источники — в `sources.json`, внешний вид — в `src/theme.css` (CSS-переменные: цвета, шрифты, отступы, длительность анимаций; комментарии на русском).
- Режим редактирования в браузере: при `?edit=1` в dev-режиме текстовые блоки становятся contenteditable, сверху панель «Сохранить», которая через dev-эндпоинт Vite записывает изменения обратно в соответствующий .md-файл (с сохранением сносок `[^N]` и Markdown-разметки). Плюс кнопка «Отменить изменения». В production-сборке этот режим полностью вырезан.
- `EDITING.md` на русском: где что лежит, как поменять текст, цифру, цвет, картинку, видео, как пересобрать и задеплоить.

## 5. Анонимность (критично — за указание авторства дисквалифицируют)

- Нигде на сайте, в метатегах, комментариях, package.json, README, именах файлов — никаких имён, ников, email, ссылок на соцсети.
- Подвал — только список источников, без копирайта с именем.
- Перед `git init` настрой локально для репозитория `user.name "media-project"` и `user.email "media-project@users.noreply.github.com"`; глобальный конфиг не трогай.
- В конце — grep по проекту на персональные данные и отчёт.

## 6. Визуальная концепция и переходы

Метафора — путешествие Маши: посадочный талон, штампы в паспорте, маршрут на карте. Каждый раздел — «остановка». Сбоку (на мобильном — сверху) прогресс-бар маршрута с точками-остановками; клик — переход к разделу.

ПЕРЕХОДЫ между ВСЕМИ разделами анимированы (GSAP ScrollTrigger, pin/scrub): перелистывание страницы паспорта, пролёт пунктирной линии маршрута, морфинг цвета фона, «въезд» следующей остановки. Переход не дольше одного экрана скролла и не мешает чтению.

В КАЖДОМ разделе — анимация появления текста и минимум один интерактивный элемент.

## 7. Разделы и интерактив

**00 Обложка** (`00-oblozhka.md`). Посадочный талон «Москва → Мир», пассажир «Маша». Заголовок анимируется вариативным шрифтом. Подсказка «листайте».

**01 Парадокс** (`01-zavyazka.md`). Split-screen с двумя счётчиками, стартующими при появлении: слева — «Netflix: 8-й и 9-й сезоны, 100+ стран», справа — «−46%» ($8,5 млн → $4,6 млн из data.json). Ползунок, которым пользователь «перетягивает» экран между половинами.

**02 Кто едет** (`02-kto-edet.md`).
- Линейный график `boxOfficeAbroadYears`, линия рисуется при скролле. Неполные периоды `boxOfficeAbroadPartial` — отдельной вставкой, НЕ на той же линии.
- Пончик «≈⅔ кассы — анимация», сегмент вырастает при появлении.
- Bar chart `top5Abroad2024`, анимация выделена цветом, переключатель «только анимация».
- Карточка «20% → 30%» с анимированным счётчиком.

**03 Карта маршрута** (`03-karta.md`). Карта мира D3, вкладки «2024» / «янв–сен 2026» (`markets2024`, `markets2026_9m`): страны плавно перекрашиваются, из Москвы рисуются пунктирные маршруты, тултипы по наведению/тапу. Отдельная плашка «Латинская Америка ≈ ⅓ кассы».

**04 Таможня** (`04-tamozhnya.md`). Разворот паспорта; при скролле на него «падают» штампы «ОТКАЗАНО», «НА ПРОВЕРКЕ», «ПОДДЕРЖКА ПРИОСТАНОВЛЕНА», «РЕПУТАЦИЯ» с анимацией удара. Каждый жирный абзац раздела (`**Отказано.**` и т.д.) — содержимое карточки, которая раскрывается по клику на штамп.

**05 Почему Маша проходит границы** (`05-lokalizatsiya.md`).
- Компонент «сравнение озвучек»: вкладки RU / EN / ES / AR, в каждой слот `<video>` с подписью «Фрагмент приведён в информационных целях. Источник: …». Медиафайлы добавлю сама — сделай пустые слоты (`media/masha-ru.mp4` и т.д.) с красивой заглушкой.
- Карточки-флипы с цифрами из `data.json → masha` (у «25+ языков» на обороте пометка «данные 2017 года»).
- Цитата Бырдина — выноска с анимацией «печатания».

**06 Чемодан денег** (`06-chemodan.md`). Чемодан открывается при скролле, внутри — treemap «касса / права и стриминг / мерч», пропорция мерча из `masha.merchShare` с подписью «оценка Bloomberg, 2015».

**07 Куда дальше** (`07-stsenarii.md`). Три кнопки-сценария; линия прогноза 2023–2030 плавно перестраивается от `animationAbroad2023` к значениям `scenarios`, горизонтальная пунктирная линия цели `animationTarget2030`. Подпись на графике «Прогноз автора, не данные». Текст сценария под графиком меняется вместе с кнопкой.

**08 Прибытие** (`08-vyvod.md`). Посадочный талон получает штамп «ПРИБЫЛА», текст вывода.

**Источники** — из `sources.json`, пронумерованный список с датами и ссылками.
