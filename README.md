# Маша едет за границу

Мультимедийный лонгрид (scrollytelling) об экспортном потенциале российской анимации.

Статический сайт: Vite + vanilla JS + CSS. Все библиотеки (GSAP, Lenis, D3, markdown-it) и шрифты
(Google Sans Flex, Roboto Flex, PT Mono) устанавливаются через npm и попадают в сборку.
Сайт не обращается к сторонним доменам, не использует аналитику, трекеры и cookies.

## Быстрый старт

Нужен Node.js 18 или новее.

```bash
npm install
```

```bash
npm run dev
```

Откройте http://localhost:5173. Чтобы править текст прямо в браузере, откройте http://localhost:5173/?edit=1.
Подробнее о том, где что лежит и как менять текст, цифры, цвета и видео, — в [EDITING.md](EDITING.md).

## Сборка

```bash
npm run build
```

Готовый сайт появится в папке `dist/`. Все пути в нём относительные.
Посмотреть сборку локально:

```bash
npm run preview
```

## Проверки

```bash
npm run check
```

Ищет персональные данные (имя пользователя, git-имя и email, адреса почты, ссылки на соцсети,
копирайты, абсолютные пути) и внешние подключения в коде и сборке.

```bash
npm run qa
```

Требует запущенного `npm run preview` и установленного Chrome. Проверяет ширины 375 / 768 / 1440 px,
режим без анимаций, сторонние запросы, ошибки консоли и запускает Lighthouse. Отчёт и скриншоты сохраняются в `.qa/`.

## Публикация на GitHub Pages

Сборку и публикацию делает GitHub Actions (`.github/workflows/pages.yml`), папку `dist/` коммитить не нужно.

1. Перед первой отправкой проверьте анонимность: `npm run check` (покажет локальные git-имя и email).
2. Создайте пустой репозиторий в анонимном аккаунте GitHub и подключите его:

```bash
git remote add origin https://github.com/<аккаунт>/<репозиторий>.git
```

```bash
git push -u origin main
```

3. В репозитории: Settings → Pages → Build and deployment → Source: **GitHub Actions**.
   После каждого `git push` сайт пересобирается сам (вкладка Actions показывает ход сборки).

Сайт будет доступен по адресу `https://<аккаунт>.github.io/<репозиторий>/`.
