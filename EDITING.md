# Как редактировать сайт

Всё содержимое лежит в папке `content/`, внешний вид — в `src/theme.css`.
Код трогать не нужно.

## Где что лежит

| Что | Где |
|---|---|
| Текст разделов | `content/00-oblozhka.md` … `content/08-vyvod.md` |
| Цифры для графиков и счётчиков | `content/data.json` |
| Список источников (сноски) | `content/sources.json` |
| Видео для блока «Сравнение озвучек» | файлы — `public/media/`, настройки — `content/media.json` |
| Цвета, шрифты, отступы, скорость анимаций | `src/theme.css` |
| Подписи интерфейса: кнопки, вкладки, талон, подсказки, надписи на графиках, названия остановок | `content/ui.json` |

## Запуск для правок

```bash
npm install
```

```bash
npm run dev
```

Откройте http://localhost:5173. После сохранения любого файла страница обновится сама.

## Текст

**Вариант 1: в файле.** Откройте нужный `.md` в любом редакторе (Блокнот, VS Code) и правьте.
- Абзацы разделяются пустой строкой.
- `**жирный**`, `*курсив*`, `[текст ссылки](https://адрес)`.
- Сноска — `[^N]`, где N — `id` источника из `sources.json`. Номер на сайте совпадает с N, по клику
  подсвечивается источник внизу, при наведении — название издания и дата.
- `## Остановка 1. Парадокс` — заголовок раздела. Часть «Остановка 1.» сама оформится штампом.
- В разделе «Таможня» абзацы, начинающиеся с `**Слово.**`, становятся штампами на паспорте.
- В разделе «Куда дальше» каждый блок `### Сценарий …` — текст одной кнопки-сценария
  (порядок блоков = порядок сценариев в `data.json → scenarios`).

**Вариант 2: в браузере.** Откройте http://localhost:5173/?edit=1 — см. раздел «Редактор в браузере» ниже.

## Редактор в браузере (`?edit=1`)

Запустите `npm run dev` и откройте http://localhost:5173/?edit=1. Внизу появится панель инструментов.

**Что правится прямо на странице** (обведено синим пунктиром — щёлкните и печатайте):
- абзацы и заголовки статьи → сохраняются в нужный `.md` (сноски и **жирный**/*курсив* не теряются; Ctrl+B / Ctrl+I);
- простые подписи: заголовки графиков, примечания, подсказки, подписи карточек → сохраняются в `content/ui.json`.

**Что правится в боковой панели** (кнопка «Панель», вкладки):
- **Цифры** — `data.json`: значения графиков и счётчиков, периоды, номера источников, сценарии;
- **Подписи** — `ui.json`: всё, что на кнопках, вкладках, талонах, внутри графиков, и подписи с подстановками вроде `{period}`;
- **Видео** — `media.json`: файлы, источники, `ready`;
- **Источники** — `sources.json`: название, издание, дата, ссылка.

Поиск сверху ищет по названию поля и по значению. Изменённые поля подсвечиваются жёлтым.

**«Выбор элементов»** (галочка на панели инструментов, включена по умолчанию): щёлкните по любой
цифре, столбику, точке на графике, стране на карте, вкладке, кнопке сценария, карточке-флипу —
откроется панель на поле, которое за это отвечает. Элементы, которые можно выбрать, подсвечиваются
оранжевым при наведении. Чтобы проверить, как элементы работают (переключить вкладку, перевернуть
карточку), снимите галочку.

**Сохранить** записывает все изменения сразу во все файлы и перезагружает страницу на том же месте.
**Отменить изменения** возвращает всё несохранённое. Меняются только сами значения — ручное
форматирование JSON-файлов сохраняется как есть. Цифры можно менять на цифры, текст на текст:
если ввести текст в числовое поле, сохранение откажется и покажет, что не так.

Подписи меняются на странице сразу, цифры на графиках — после «Сохранить».
Режим работает только в `npm run dev`; в готовую сборку (`npm run build`) редактор не попадает.

Если какой-то подписи не нашлось в `ui.json`, на странице будет видна метка вида `⟨map.title⟩` —
значит, ключ удалён или переименован.

## Цифры

Откройте `content/data.json`. У каждого значения есть `value` (число), `sourceId` (номер источника)
и иногда `note` (подпись). Графики берут цифры только отсюда — меняете число, меняется график.
Числа пишутся с точкой: `16.6`, а не `16,6`. Доли — от 0 до 1: `0.67` = 67%.

Примеры:
- Сборы 2024 года → `boxOfficeAbroadYears`, строка с `"period": "2024"`.
- Значения сценариев на 2030 год → `scenarios.streaming["2030"]` и т. д.
- Доля мерча → `masha.merchShare.value`.

Если добавляете страну в `markets2024` / `markets2026_9m`, укажите её трёхбуквенный код `iso`
(например, `"COL"`). Если страны нет в справочнике в начале `src/charts/map.js`, добавьте её туда.

## Источники

`content/sources.json`: `id`, `title`, `outlet`, `date` (`ГГГГ-ММ-ДД` или `ГГГГ-ММ`), `url`.
Новый источник — новая запись с новым `id`, в тексте — `[^id]`.

## Цвета, шрифты, анимации

`src/theme.css`, каждый параметр подписан по-русски:
- `--c-anim` — цвет анимации на графиках, `--c-passport` — бордовый, `--c-route` — синий.
- `--bg-00` … `--bg-09` — фон каждой остановки (плавно сменяют друг друга).
- `--fs-h1`, `--fs-h2`, `--fs-body` — размеры шрифтов.
- `--dur-fast / --dur-base / --dur-slow` — длительности анимаций; `--motion-scale: 0.5` — всё вдвое быстрее.
- `--transit-h` — длина переходов между остановками.

## Картинки

Кладите в `public/img/` в формате **WebP** (конвертер: `cwebp in.png -o out.webp` или любой онлайн-конвертер,
работающий локально). В тексте `.md`: `![Описание картинки для незрячих](img/имя.webp)`.
Перед добавлением удалите метаданные (автор, GPS) — `npm run check` их найдёт.

## Видео

1. Положите файл в `public/media/` (имена: `masha-ru.mp4`, `masha-en.mp4`, `masha-es.mp4`, `masha-ar.mp4`).
2. В `content/media.json` у этого языка поставьте `"ready": true` и впишите `"source"`.
3. Обложка (необязательно): `public/media/masha-ru.webp` и `"poster": "media/masha-ru.webp"`.

Удалить метаданные из видео: `ffmpeg -i in.mp4 -map_metadata -1 -c copy masha-ru.mp4`.

## Пересобрать и опубликовать

```bash
npm run build
```

```bash
npm run check
```

```bash
git add -A
```

```bash
git commit -m "Правки текста"
```

```bash
git push
```

После `git push` GitHub Actions сам пересоберёт и опубликует сайт (см. README.md).
